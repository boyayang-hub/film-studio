# Film Studio

Paste a storyboard from the demo-film assistant, load your voice clips, preview the film and record it as an MP4, all in Chrome.

**Open it:** https://boyayang-hub.github.io/film-studio/

Everything runs in your browser: storyboards and voice clips never leave your computer.

This repo holds only the built page. It is generated by `studio/build_studio.py` in the demo-film skill project; don't edit `index.html` by hand.
